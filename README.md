# bibi-flap
A game for Bibi

## Initial Prompt
Create a game playable in the browser and deployable as a static website. The game is a 2D flying game where the player will choose from 4 characters (cat, dog, bee or book). The game objective is to fly (using the space bar) over some obstacles and capture as many donuts as possible until the end of the phase.
Make 4 levels initially.
The game must have a tutorial level to teach the player how to play the game.
